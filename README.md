## About the Project

Grosters needed a production-ready commercial website. 
I handled the entire project independently — client communication, 
design implementation, development, optimization, and final handoff.

---

## Features

- Fully responsive layout across 3 breakpoints 
  (mobile / tablet / desktop)
- Cross-browser consistent rendering — iOS Safari, Chrome, 
  Firefox, Edge
- Interactive modal windows and smooth animations
- Modular UI sections in vanilla JavaScript — no framework
- Semantic HTML5 + BEM-style CSS architecture for 
  maintainable codebase
- Optimized assets — compressed images, minified CSS/JS
